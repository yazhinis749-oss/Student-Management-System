# Student Management System in C

## Project Description
The Student Management System is a console-based application developed using the C programming language. It helps manage student records efficiently using a linked list and file handling.

## Features
- Add new student records
- Display all student records
- Update student details
- Search students using roll number
- Sort students alphabetically by name
- Delete student records
- Save student details to a file
- Load previously saved records automatically

## Technologies Used
- Programming Language: C
- Data Structure: Singly Linked List
- File Handling: Binary File Handling
- Memory Management: Dynamic Memory Allocation
- Compiler: GCC
- Build Tool: Makefile

## Project Structure
- `mainfile.c` – Main menu and program execution
- `student_add.c` – Add student records
- `student_show.c` – Display student records
- `student_modify.c` – Update student records
- `student_search.c` – Search student records
- `student_sort.c` – Sort student records
- `student_delete.c` – Delete student records
- `student_save.c` – Save student records
- `student_load.c` – Load student records
- `student.h` – Header file
- `makefile` – Build configuration

## How to Compile

Make sure GCC and Make are installed.

```bash
make
```

## How to Run

```bash
./student
```

On Windows, run:

```bash
student.exe
```

## How to Clean Build Files

```bash
make clean
```

## Learning Outcomes
This project demonstrates practical knowledge of C programming, structures, pointers, linked lists, recursion, dynamic memory allocation, file handling, and modular programming.
